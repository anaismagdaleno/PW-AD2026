# Comandos Git
## 1. git init
**Descripción:** Inicializa un repositorio Git en la carpeta actual.
**Ejemplo de uso:** `git init`

## 2. git clone
**Descripción:** Descarga una copia de un repositorio remoto.
**Ejemplo de uso:** `git clone https://github.com/user/repo.git`

## 3. git status
**Descripción:** Muestra el estado de los archivos (modificados, staged, etc.).
**Ejemplo de uso:** `git status`

## 4. git add
**Descripción:** Agrega archivos al área de staging.
**Ejemplo de uso:** `git add archivo.md`

## 5. git add .
**Descripción:** Agrega todos los archivos modificados al staging.
**Ejemplo de uso:** `git add .`

## 6. git commit
**Descripción:** Guarda los cambios del staging en el historial.
**Ejemplo de uso:** `git commit -m "Agrega perfil"`

## 7. git push
**Descripción:** Sube los commits locales al repositorio remoto.
**Ejemplo de uso:** `git push origin main`

## 8. git pull
**Descripción:** Descarga y fusiona cambios del repositorio remoto.
**Ejemplo de uso:** `git pull origin main`

## 9. git fetch
**Descripción:** Descarga cambios remotos sin fusionarlos.
**Ejemplo de uso:** `git fetch origin`

## 10. git branch
**Descripción:** Lista, crea o elimina ramas.
**Ejemplo de uso:** `git branch nueva-rama`

## 11. git checkout
**Descripción:** Cambia de rama o restaura archivos.
**Ejemplo de uso:** `git checkout nueva-rama`

## 12. git switch
**Descripción:** Cambia de rama (alternativa moderna a checkout).
**Ejemplo de uso:** `git switch main`

## 13. git merge
**Descripción:** Une los cambios de una rama a otra.
**Ejemplo de uso:** `git merge nueva-rama`

## 14. git log
**Descripción:** Muestra el historial de commits.
**Ejemplo de uso:** `git log --oneline`

## 15. git diff
**Descripción:** Muestra las diferencias entre archivos o commits.
**Ejemplo de uso:** `git diff`

## 16. git remote -v
**Descripción:** Muestra los repositorios remotos configurados.
**Ejemplo de uso:** `git remote -v`

## 17. git reset
**Descripción:** Deshace cambios en el staging o el historial.
**Ejemplo de uso:** `git reset --soft HEAD~1`

## 18. git revert
**Descripción:** Crea un commit que deshace cambios de otro commit.
**Ejemplo de uso:** `git revert a1b2c3d`

## 19. git stash
**Descripción:** Guarda cambios temporalmente sin hacer commit.
**Ejemplo de uso:** `git stash`

## 20. git config
**Descripción:** Configura opciones de usuario, como nombre y correo.
**Ejemplo de uso:** `git config --global user.name "Anais"`
